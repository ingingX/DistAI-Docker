# DistAI-Docker 

This is my solution for Sereact Assignment, demonstrating a simulated **distributed AI inference architecture** using Python and Docker.

It includes:
- A central **Coordinator** service that handles worker nodes and dispatches tesk requests
- Three **Worker services** running different pretrained models (BERT, MobileNet, CLIP)
- Basic health checks, load-based routing, and a testing script

## Structure

```
distributed_inference_system/
├── coordinator/
│   ├── coordinator.py          # Coordinator service handling API and task routing
│   ├── Dockerfile              # Dockerfile for Coordinator
│   └── requirements.txt        # required Libs
├── workers/
│   ├── w1-BERT.py              # Worker 1: BERT text embedding
│   ├── w2-MobileNet.py         # Worker 2: MobileNet image classifier
│   ├── w3-CLIP.py              # Worker 3: CLIP image-text similarity
│   ├── Dockerfile              # Dockerfile for workers
│   └── requirements.txt        # required Libs
├── scripts/
│   |── test_request.py         # smoke-test
|   └── test_batch.py           # smoke-test
├── docker-compose.yml
└── README.md
```

## Build & Run

1. **Unzip and start services**:
   ```bash
   unzip DistAI-Docker.zip
   cd DistAI-Docker
   docker-compose up --build
   ```

2. **Send test inference requests**:

   2.1 ***Run from host machine***

   ```bash
   python scripts/test_request.py --api http://localhost:8000/infer --mode text --text "This is a BERT test"
   python scripts/test_request.py --api http://localhost:8000/infer --mode image --image_url "https://picsum.photos/256"
   python scripts/test_request.py --api http://localhost:8000/infer --mode both --text "This is a CLIP test" --image_url "https://picsum.photos/256"
   ```

   2.2 ***Run from within Docker container***

   ```bash
   docker-compose exec coordinator python /scripts/test_request.py --mode text --text "test BERT input"
   docker-compose exec coordinator python /scripts/test_request.py --mode image --image_url "https://picsum.photos/256"
   docker-compose exec coordinator python /scripts/test_request.py --mode both --text "a cat" --image_url "https://picsum.photos/256"
   ```


3. **Monitor status**:
   ```bash
   curl http://localhost:8000/status
   ```

## Routing Logic

The coordinator routes requests based on input:
- `--mode text` Text only → BERT Worker (w1-BERT)
- `--mode image` Image only → MobileNet Worker (w2-MobileNer)
- `--mode both` Text + Image → CLIP Worker (w3-CLIP)

## Features

- Health check for workers (via `/status`)
- Retry logic and error logging
- Manual testing support via `test_request.py`
- Auto testing support via `test_batch.py`. It sends 21 requests to Coordinator.
- Logs last 10 inferences via `/status`

## Models Used

- `prajjwal1/bert-tiny`: a lightweight, distilled version of BERT (Bidirectional Encoder Representations from Transformers).
- `torchvision.models.mobilenet_v3_small`: a light but reasonable accuracy CNN for image classification.
- `openai/clip-vit-base-patch32`: a small veriant of CLIP (Contrastive Language–Image Pre-training) for image–text matching.
